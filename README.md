# AI Career Advisor

An AI-powered career recommendation system built using:

- Streamlit
- Google Gemini API
- ChromaDB
- Python

## Features

- Career recommendations based on interests
- AI-powered career guidance
- Career-specific Q&A
- Semantic search using ChromaDB

## Tech Stack

- Python
- Streamlit
- ChromaDB
- Google Gemini API
- GitHub
- Streamlit Cloud

## Live Demo

[AI Career Advisor](https://ai-career-advisor-zg6utnaftb95tkahb4ilow.streamlit.app/)
## How It Works

1. User enters interests.
2. ChromaDB retrieves the most relevant careers.
3. User selects a career.
4. Gemini answers career-specific questions.
5. Recommendations and guidance are displayed through Streamlit.
